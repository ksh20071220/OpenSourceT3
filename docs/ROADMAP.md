## 제안서 그림 2 항목별 담당

| 그림 2 항목 | 담당 | 위치 |
|---|---|---|
| 사용자 입력 (이름, 추가 키워드, 실무 요청, 결과 확인·수정) | 곽수호 | `ui/screens/CreateScreen.jsx`, `EditScreen.jsx` |
| 웹 검색 | 오승민 | `apiSearch` (회사 내장 검색 도구) |
| 자료 정제·필터링 (신뢰도 평가, 중복 제거) | 손석현 | `persona/generate.js` |
| 인격 정보 추출, 페르소나 구조화 | 손석현 | `persona/generate.js`, `persona/prompt.js` |
| 로컬 저장소: 페르소나 | 손석현 → 오승민 | `savePersona` → `storage/personasStore` |
| 로컬 저장소: 대화 기록 | 오승민 | `memory/`, `storage/conversationsStore` |
| 로컬 저장소: 참고 자료 캐시 | 손석현 | (후순위) |
| 사용자 입력 처리 (의도·대화/실무 분류) | 공통 + 곽수호 | 목적 선택 (`purposes.json`, `PurposePicker`) |
| 모델 라우팅 | 오승민 | `apiChat` (목적의 `tier`) |
| LLM API 연동 (스트리밍, 모델별 파라미터) | 오승민 | `api/providers/` |
| 출력 후처리 (형식 정리, 안전성 필터링, 출처 표시) | 오승민 | `api/api.js` `postProcess` |
| 대화 기록 및 기억 관리 (요약·장기 기억) | 오승민 | `memory/` |
| 실용 업무 지원 | 공통 | 1차는 목적 지시문으로 대응, 도구 연동은 5단계 |
| 외부 도구 (RAG, 코드 실행, 일정 등) | **미정** | 5단계 |
| 인격 일관성 검증 (단순 프롬프트와 비교) | **미정** | 4단계. 비교 모드(`baseline`)는 준비됨 (프로필 화면 체크박스) |
